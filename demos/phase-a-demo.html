Phase A.2 — streaming readers

Live streaming demo

Runs mockTokenStream() through createTokenStreamBody(). The blinking block cursor is the .tk-stream::after pseudo-element; it stops when finalize() applies .tk-stream-done. rAF coalescing inside append() keeps the DOM writes capped at 60 Hz even at 1 ms/token.

Runtime-only kinds reference

Node kinds that skip C++ codegen and dispatch via JS subsystem routers instead (mirrors how RayTracedScene already works with kind: "scene-rt").

  • "llm-op" — pure tensor ops (MultiHeadAttention, LayerNorm, FFN, …). Dispatcher: src/llm/dispatcher.js (Phase D).
  • "llm-sink" — side-effecting LLM endpoints (TrainStep, Generate, Chat). Phase B (Ollama) + Phase D.
  • "llm-viz" — render LLM state to a texture port (AttentionGraph3D, LossPlot, …). Phase D.
  • "notes-source" — streams tokenized notes from the Tektite MD vault. Phase C (src/tektite/corpus.js).
